# 生成图的调用契约与独立分发边界是什么？

## Question

前置决策：[行为保真](01-fidelity-contract.md)、[转换依据](02-conversion-evidence.md)、[运行能力与权限](03-runtime-capabilities.md)。

如何区分转换 Skill 的输入输出、源 Skill 的业务契约，以及生成图所需的调用封装和运行配置？现有默认 `messages/artifacts` 建议是否适用，如何避免额外字段、结构化输出机制或文件内容的搬运改变源业务契约？

明确生成目录需要包含哪些源包资源、图入口、依赖声明、工具绑定与运行说明，哪些内容仍由调用方提供。源包可包含任意目录，不仅限于 `references/scripts/assets`；如何保留其实际引用关系？如何区分源 Skill 名称、graph ID 与 Python 模块名，处理名称和目录不一致的情况？同时明确 Python 与 CLI 的加载、暂停恢复和持久化职责，避免把服务端专属能力变成纯 Python 的隐式前提。

依照 [AGENTS.md](../../../AGENTS.md) 的发布边界确定依赖声明和交付内容；项目验收环境属于仓库资产，不纳入转换 Skill 包或生成图。

参考：[默认契约与产物示例](../../../references/skill-to-langgraph-mapping.md)、[包资源约定](../../../references/agent-skills-package-format.md)、[Python 与服务运行差异](../../../references/langchain-cli-and-deployment.md)。答案需给出契约边界和最小交付约定，无需实现目录或模板。

## Answer

用户已确认以下契约及交付约定：

- 图可以采用 LangGraph 所需的调用封装，但须明确说明源输入如何传入、业务结果如何取出；业务含义、输出格式和文件产物保持不变。`messages` 等框架字段可以承载调用过程，不据此强制源 Skill 接受新的业务字段或统一返回 `messages/artifacts`。
- 完整携带源 Skill 包的资源与相对目录结构，与新生成图代码分开放置。保持源引用语义，区分源包位置与用户工作目录；迁移产物后不依赖转换时原包的绝对路径，已声明的外部运行依赖仍由环境提供。

契约示例：源 Skill 要求生成 CSV 文件，图仍须生成该文件，不能用状态中的 CSV 字符串替代。

### 最小交付内容

每份生成产物至少包含完整源包、可导入的图代码、`langgraph.json`、依赖声明和简明运行说明。说明覆盖输入输出映射、外部依赖、配置方法及 Python 与 CLI 两种调用方式；其他文件按实际需要增加。

交付物是可独立搬移的图应用目录，外部运行条件显式声明。项目验收环境属于仓库资产，不随产物分发；独立搬移不意味着产物自带所有外部工具、服务或凭据。

### 共用图逻辑，按入口接入运行设施

Python 与 CLI 使用同一套构图逻辑。需要会话存储等设施时，Python 允许调用方提供，CLI 使用服务运行时提供的设施；公共图逻辑不写死具体后端，两种入口保持相同业务语义。

导出已编译图还是图工厂，按实际配置需求选择，不强制每份产物同时提供两套入口。Python 导入路径、依赖声明和 CLI 配置须与实际交付布局一致。

### 名称与技术标识

保留源 Skill 名称，graph ID 在目标允许时沿用源名；Python 模块名、变量名使用合法技术标识。需要转换名称时明确记录对应关系，不改写源包来迁就代码命名。

例如，`data-analysis` 可以保留为源名和兼容目标下的 graph ID，不能直接充当 Python 变量名。若包内名称存在影响契约的矛盾，按[转换依据议题](02-conversion-evidence.md)确认的冲突处理原则澄清。

### 开发参考中需要校正的建议

后续编写转换指令及分发资料时，按本票已确认的规则核对：

- [转换映射参考](../../../references/skill-to-langgraph-mapping.md) §1 的默认 `messages/artifacts` 仅能作为具体适用场景的调用示例，不能固定为所有源 Skill 的业务契约；框架状态与业务结果的取得方式须分别说明。
- 同一参考 §2 不能将含连字符的源名直接作为 Python 变量名；§8 的根目录资源布局与“源脚本加转换器脚本”示例须按完整源包和生成代码分开放置的原则调整，转换器自身脚本是否进入产物取决于运行是否实际需要。
- [CLI 与部署参考](../../../references/langchain-cli-and-deployment.md) §10 的图入口、Python 导入与配置示例须按实际布局统一；不能将 `from src...` 当作通用导入约定，也不强制同时导出图对象和工厂。环境配置文件按实际需要提供。

转换 Skill 仍以合法源包路径为输入，输出本票定义的图应用目录；图调用封装不是转换 Skill 新增的必需输入。本票结案。
