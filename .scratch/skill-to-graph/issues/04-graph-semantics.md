# 固定流程、自主决策和混合流程如何映射为图？

Type: grilling
Status: resolved
Parent: [skill-to-graph 首版转换决策地图](../map.md)
Blocked by: 01, 02, 03

## Question

前置决策：[行为保真](01-fidelity-contract.md)、[转换依据](02-conversion-evidence.md)、[运行能力与权限](03-runtime-capabilities.md)。

在已明确的保真要求、转换依据和运行能力下，什么流程必须编码为图控制流，什么行为应保留给模型判断？一个 Skill 同时包含固定阶段和自主工具选择时，如何选择整体结构、节点边界及状态，既保留约束也避免擅自固定源 Skill 留给模型的自由度？

明确顺序、分支、循环、并行、失败和等待用户的映射依据；判断条件不明确时应如何处理。评估现有“两条产线”建议能否覆盖混合流程，并用少量代表性场景说明选择，而非预先规定每句话对应一个节点。

参考：[转换映射参考](../../../references/skill-to-langgraph-mapping.md)、[LangGraph 核心机制](../../../references/langgraph-core.md)、[LangChain Agent 运行机制](../../../references/langchain-agent-runtime.md)。答案需形成后续编写指令可直接采用的映射规则与必要的未决问题。

## Answer

用户已确认以下六项映射规则：

- 按局部流程选择构件：固定流程采用显式节点和边，自主决策部分在满足源约束时使用 `create_agent`，混合流程组合两者。完全自主的 Skill 可以直接采用 agent 图，不额外套用没有职责的外层图。
- 条件根据明确数据可判定时使用代码，源 Skill 留给模型的语义条件由模型判断，再由图落实分支。不擅自引入字数、数量等替代源条件的门槛。
- 按独立控制阶段及恢复边界划分节点，不按句子、段落或编号机械切分。必须保证的阶段顺序、分支和人工等待须有明确落点，内部连续工作可合并；恢复可能重跑时隔离有重复副作用风险的操作。
- 状态按源流程的数据传递与恢复需求设计，需要跨节点共享或暂停后恢复的信息进入状态，局部临时值留在节点内。保留源流程需要的历史上下文，参考资料仍按需读取；不预设所有 Skill 都使用同一套状态结构，也不为方便转换而将所有资料预先塞入状态。
- 循环保留源停止条件及明确次数限制。运行时步数限制触发时，报告执行受限，不能将其视为业务完成。并行只在源流程允许、且不会改变顺序要求或副作用时使用；逐项处理本身不能直接解释为并行，汇总须保留源要求的对应关系和顺序。
- 失败处理遵循源 Skill，不额外添加图级自动重试、降级或补偿操作。区分业务重试与运行恢复；节点拆分、检查点或外部工具的幂等能力须实际支撑相应恢复行为。无法保证安全恢复的外部操作须明确限制，不能仅凭存在检查点就声称不会重复执行。

混合流程示例：“检查输入 → 自主检索 → 用户确认 → 输出报告”，由外层图固定阶段顺序，检索阶段内部保留 agent 的工具选择能力。

### 代表性场景

- 固定流程：“检查文件是否存在 → 等待确认 → 写入结果”，存在性由代码判断，图落实确认与写入的先后关系；恢复时不重复已完成的写入。
- 自主流程：“自主选择检索工具并总结”，满足源约束时可以直接采用 agent 图；提及工具不意味着必须另写整个工具循环。
- 条件循环：“资料不足则继续检索”，由模型判断资料充分性，图落实继续或结束的分支；不替换为固定检索次数。
- 集合处理：“逐项处理并按原顺序汇总”，保留逐项语义及输出顺序；是否并行需另行满足源许可和副作用条件。

### 开发参考中需要校正的建议

后续编写转换指令及分发资料时，按本票已确认的规则核对以下内容：

- [转换映射参考](../../../references/skill-to-langgraph-mapping.md) §0 的两条产线需覆盖混合流程；§3 不能按编号机械确定控制流，不能直接把逐项处理映射为 `Send` 并行，不能用重试替代源要求的失败停止；节点粒度不以能够重试为普遍前提。
- 同一参考 §3 的循环与步数限制需区分业务停止条件和运行限制；§4 的状态示例按具体源流程选用，不固化为所有 Skill 的统一通道契约。对外调用封装由[交付议题](05-generated-artifact-contract.md)继续确定。
- [LangGraph 核心参考](../../../references/langgraph-core.md) §12 中“tool-calling agent 优先手写工具循环”的转换建议，不能取代本票确认的局部构件选择原则。该资料中的 API 机制与转换结构的设计建议分别判断。

本票确定映射原则，不在规划阶段修改或生成 Skill 实现、图代码及分发资料。本票结案。
